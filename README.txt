# 🎬 React Movie Search App

This is a fully functional movie search application built with **React** and **Vite**. It allows users to search for movies, view detailed cards with posters and info, and enjoy a sleek, responsive interface. The project integrates a **backend-as-a-service** via **Appwrite** and fetches data from **The Movie Database (TMDB)** API.

> 📌 This project showcases my ability to build a real-world frontend application from scratch, integrating both external APIs and backend services.

---

## 🔧 Tech Stack

- **Frontend Framework**: React (Hooks & Components)
- **Bundler**: Vite
- **API Integration**: The Movie Database (TMDB)
- **Backend**: Appwrite (for auth/data services)
- **Styling**: CSS Modules
- **Linting**: ESLint
- **Deployment Ready**: Easily deployable on Netlify, Vercel, or Firebase
